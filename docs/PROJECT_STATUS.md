# Project status and contribution scope

Match Family is an early public source project maintained by [drzecik](https://github.com/drzecik).
There are three independent implementations, not a claimed shared engine. No external adoption,
download count, independent maintainer review or real-catalog production qualification is claimed.

## Available now

- Three local browser demonstrations, synthetic fixtures and reusable TypeScript engines.
- Executable core examples with asserted outputs and no account or store requirement.
- Locked independent dependency workspaces, lint/type checks, unit/property/contract tests and browser checks.
- A fresh local WordPress 7.0.1 / WooCommerce 10.9.4 / PHP 8.3 SQLite integration check, covering activation, cart quantities and rejected invalid requests. This does not establish a wider support matrix.
- MIT first-party source except the two GPL-2.0-or-later PHP integrations; see the license scope.
- Issue/PR guidance and private vulnerability reporting at the repository's Security tab.

The root VERIFICATION.json is the historical source-extraction check. Its test counts and limits belong
to that revision. Current checks are commit-specific; consult CI and the subsequent local verification
record rather than treating the old counts as a permanent certification.

## Useful next contributions

These are invitations, not claims that a contributor or user already exists:

- Reproduce the core quickstart on another supported operating system and report the exact environment.
- Improve English explanations alongside the default Polish demonstration interface.
- Add a minimal fictional reproduction of an unsupported matching/measurement case before changing an engine.
- Review the installation guide with a fresh local WordPress/WooCommerce sandbox.

Use [CONTRIBUTING.md](../CONTRIBUTING.md) and the existing issue form. Never post private catalogs,
customer data, installation credentials or a vulnerability in a public issue.

## What requires evidence over time

Public adoption must come from real independent users, downloads, contributions or documented use.
Local tests, example runs and maintainer commits do not substitute for that evidence. No promotional
outreach, fabricated usage, automatic issue creation or program submission is part of this change.

Hosted demos, npm/WordPress registry packages, a production rollout and wider catalog coverage are
separate future decisions. They are not implied by source availability or passing automated tests.
