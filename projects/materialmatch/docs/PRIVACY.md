# Privacy

MaterialMatch is designed for data minimization. Calculations run in the browser or the customer's
WordPress installation. The default build does not create user accounts, send telemetry, contact a
licensing server, or persist shopper measurements and cart contents.

Store operators may choose to add analytics or saved projects in a future extension. Such features
must be off by default, document purpose and retention, request appropriate consent, and keep data in
the operator's controlled systems unless a separate reviewed integration says otherwise.

Logs contain codes, configuration revision, and technical context only. They must exclude names,
addresses, IP addresses, full cart contents, free-text project notes, and raw import content.

The customer-facing privacy notice template is in `docs/legal/PRIVACY_POLICY_TEMPLATE.md` and
requires legal review for the operator's jurisdiction and actual extensions.
