# Sanitization scope

This is a source preparation of the three Match projects, not a copy of private installations or data. It preserves 26 package modules, the flooring vertical pack, both PHP integrations, generic tools, source schemas, and synthetic web/widget demonstrations.

Excluded: private researched catalog JSON, private-store installation and manufacturer price/catalog files, deployment/environment configuration, original Git history, local workshop settings, research/release narrative, previous generated artifacts and tests/screens requiring those removed private data. See SANITIZATION.json for the exact original paths and reasons. Private catalog UI is not advertised as available in the demo. The generic engines and importers remain.

Copied data consists of explicit fictional fixtures. FilterMatch keeps only records with both synthetic=true and notForProduction=true. CreatorRig uses its flagged synthetic demo and offers. MaterialMatch uses its fictional reusable test fixtures and regenerates examples. Compatibility evidence in fixtures does not claim real-world compatibility. Host-specific URLs are replaced with example placeholders. No node_modules, Composer vendor, build outputs, caches, test traces or local proof logs are in the source archive.

Existing lockfiles retain public package provenance, including public third-party author metadata. Those are not owner/customer contacts. No personal application details are in this source package.

Copy-only changes prepare local demos and prevent package publication; they do not change calculation, evaluator, schema or risk logic. Test changes cover the exported fixture scope and preserve the cross-catalog fail-closed check with an invented malformed import. Upstream private-specific tests are explicitly excluded; their removal is not evidence that private production functionality was verified.

Source preparation and automated checks do not establish legal clearance, owner approval, public adoption or program eligibility.
